# ASCII 风格双作品设计

## 已确认方向

用户选择视觉选项 A 与 C，并要求分别落盘到两个新文件夹中。现有项目的绿色终端 GIF 字符化效果可作为技术参考，但两个新作品不修改原始目录。

## 作品一：CRT 生物机械

- 文件夹：`016-crt-biomorph`
- 视觉：黑绿磷光、扫描线、低频画面漂移与红色诊断标签。
- 内容：用字符密度绘制一个会呼吸、闪烁的生物机械面孔；点击画面切换诊断/休眠状态。
- 技术：一个无依赖的 `index.html`，以 `<pre>` + CSS 动画渲染，离线可打开。

## 作品二：反精致 Zine

- 文件夹：`017-zine-ascii`
- 视觉：暖纸色、黑色字符、红蓝套印偏移、粗糙网点与拼贴标签。
- 内容：字符构成的面孔随着鼠标或触摸位置产生方向性偏移，并带有可点击的“MAKE NOISE”状态切换。
- 技术：一个无依赖的 `index.html`；用 CSS 纹理和少量 JavaScript 管理交互，离线可打开。

## 共通约束与验证

- 只使用 ASCII/Unicode 文本形状，不引入图片、字体下载或第三方库。
- 各作品在 320px 至宽屏视口可阅读，优先等宽字符的完整构图。
- 验证方式：本地 HTTP 服务下打开两个页面，确认无控制台错误、动画或交互可见，且无外部网络请求。
