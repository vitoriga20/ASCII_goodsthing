# Asciify WebM 单页导出界面设计

## 目标

在 `vedio2ASCII` 中提供中文单页界面，使用 Asciify 预览并导出本地视频为保留原音频的 WebM。用户不需要输入命令，视频不会上传。

## 页面与交互

页面只保留视频选择、开始导出、ASCII 预览和进度状态。选择视频后等待它可播放，再生成首帧；导出期间显示已处理秒数、百分比和按钮禁用状态；成功后自动下载 WebM。

## 实现

页面继续从本地编译的 Asciify 模块加载 `createAsciify`。视频按可用帧回调送入渲染器；Canvas 视频轨与源视频的音频轨合并为 `MediaStream`，再经 `MediaRecorder` 输出 WebM。页面检测 WebM 录制支持、视频加载失败和缺少音频轨，并给出中文提示。

## 验证

保留导出命名与编码参数测试；在 Chrome 中检查视频加载后导出按钮启用、实时状态更新和 WebM 下载事件。原始视频及音频不被修改。
