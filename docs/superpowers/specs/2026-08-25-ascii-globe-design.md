# ASCII Globe Design：库迁移与仪表台演示页

## 目标

在 `ascii-globe-design` 中保留可复用的 TypeScript ASCII 地球渲染库，并提供一个可独立启动的浏览器演示页。演示页使用现代 ASCII/终端视觉语言，底部参数区采用 **C / Instrument Deck** 方案。

## 范围

### 迁移内容

- 迁移渲染核心：`Globe`、纹理解码与类型定义。
- 迁移内置地球、死星两张纹理地图。
- 保持库的默认导出与 `GlobeOptions`、`Pin` 接口，使核心可被独立导入。

### 不迁移内容

- 不迁移参考项目的 CLI。
- 不迁移 `node_modules`、`dist`、临时输出和截图。
- 不复制旧浏览器示例的样式与表单布局；演示页重新实现。

## 目录与职责

```text
ascii-globe-design/
  src/
    index.ts                 # 可复用 Globe 类及公开类型
    decode.ts                # 纹理解码
    maps/earth.ts            # 默认地球纹理
    maps/death-star.ts       # 死星纹理
    demo/
      main.ts                # 演示页启动、渲染循环、事件绑定
      state.ts               # 参数规范化、默认值与状态转换
      styles.css             # ASCII 仪表台视觉与响应式布局
  index.html                 # 演示页入口
  package.json               # 构建、测试、预览脚本
  tests/
    state.test.ts            # 参数与重置行为
    globe.test.ts            # 核心渲染冒烟验证
```

## 演示页交互

演示页状态包括：地图预设、尺寸、旋转速度、倾角、陆地字符、水域字符、水平/垂直旋转角度和播放状态。

- 地图支持 Earth 与 Death Star；切换时加载对应地图与主题色。
- 尺寸、倾角、地图、陆地字符和水域字符变化时，重建 `Globe` 实例并立即渲染。
- 速度由左侧圆形读数与滑动控制共同表达；动画使用 `requestAnimationFrame` 的时间差以保持不同刷新率下的运动一致性。
- 地球区域支持鼠标与触摸拖拽，分别更新水平和垂直角度；垂直角度限制为 -90° 至 90°。
- 暂停按钮停止/恢复动画；重置按钮恢复所有默认参数与初始视角。

## Instrument Deck 面板

面板固定在地球下方，由三个区域构成：

1. 左侧速度圆盘：显示当前速度值与旋转状态，点击暂停时切换为静止读数。
2. 中部读数栈：尺寸、倾角、陆地字符与水域字符，以等宽数字/字形呈现；可通过紧凑输入或步进控件编辑。
3. 右侧操作区：地图预设切换、暂停/继续与重置。

窄屏宽度下，面板依序堆叠为速度圆盘、关键读数和操作区；控件仍能使用键盘访问。

## 视觉规范

- 背景使用近黑绿色与低对比网格，不使用纯黑大面积空白。
- 主操作和焦点为荧光黄绿；数值为青色；辅助文字为低饱和绿色。
- 控件采用细描边、像素感阴影、终端状态文案与轻微 CRT 光晕。
- 保持高对比度焦点态，避免只用颜色区分暂停、选中和错误状态。
- 使用系统等宽字体栈；不引入外部字体或图片依赖。

## 数据流与安全性

用户操作先进入 `state.ts` 做数值解析、范围限制与字符规范化，再驱动核心实例和 DOM 渲染。

- 尺寸限制为 0.6–2.0。
- 速度限制为 0–3.0；倾角限制为 -90°–90°。
- 陆地与水域字符只接受一个可显示字符；空值或非法值回退到 `#` 和 `-`。
- HTML 颜色输出对字符内容进行转义，避免用户输入通过 `innerHTML` 注入页面。

## 错误处理

- 无效数值会在失焦或提交时回退到上一个有效值，并在控件旁显示短暂的终端式提示。
- 地图预设不可用时回退到 Earth，并保持页面可渲染。
- 渲染异常在演示页状态栏中显示，不使动画循环持续报错。

## 测试与验收

采用 Vitest。实现按测试先行推进。

- `state.test.ts` 覆盖默认状态、范围限制、字符回退与重置。
- `globe.test.ts` 验证默认地球可以输出非空多行 ASCII、旋转后仍保持有效输出，以及死星地图可渲染。
- 运行测试、生产构建和本地预览检查。
- 验收时验证：所有控件实时生效、拖拽正常、暂停/重置正确、小屏布局不遮挡、键盘焦点清晰。
