# MORPH / ASCII Studio 产品推荐页设计

## 目标

制作一张单页产品推荐网页，介绍一款将图片、视频和 GIF 转化为 ASCII 视觉内容的创作软件。页面应以深色夜行氛围、大面积留白和高质量实时字符动效为主，而不是传统的“绿字黑底终端”模板。

## 视觉定位

- 名称：MORPH / ASCII Studio。
- 气质：安静、精密、电影感，带深绿磷光与暖象牙色高光。
- 参考：Glyph 的字符层次与控制感；Gossamer 的低密度环境动效。
- 默认优先级：桌面端特效优先。移动端仍保留字符云雾、扫描、显影和交互反馈，只降低字符网格密度与绘制频率。
- 不使用“满屏矩阵雨”、霓虹粉蓝配色或不可读的密集终端 UI。

## 页面结构

1. 固定顶栏：产品标识、简短定位、导航定位和主行动按钮。
2. 沉浸首屏：产品名、主标题、简述、主按钮与真实主图。图像周围有实时字符云雾、颗粒、慢速扫描光和鼠标扰动。
3. 输入媒介区：三个真实输入入口——图片、视频、GIF；用字符化小型动态图形强调“任意媒介都能成字”。
4. 视频转码区：使用舞者转换图，叙述逐帧转换、速度与导出能力。滚动进入时覆盖一层会流动和重组的实际字符网格。
5. 创作控制区：使用 GIF 控制台图，讲述字符集、密度、抖动、色彩和图层。控件卡片有可悬停的微交互。
6. 收束行动区：大号 ASCII 字符装置、试用主按钮和短产品承诺。

## 真实 ASCII 机制

### 动态背景

Canvas 上维护实际字符单元（例如 `· : + * # @`），而非图片或预先绘制的字符截图。字符位置、透明度和选择与时间、鼠标位置、噪声场相关；形成稀疏云雾、光点和扫描波。

### 章节字符网格

每个动态章节将有真实 `<canvas>` 字符网格。网格从抽象亮度场生成字符密度，随滚动及鼠标缓慢重组。它作为视觉层，内容区仍使用语义化 HTML。

### 顶级动效范围

- 首屏字符云雾、浮游颗粒与扫描光；
- 鼠标靠近时的字符吸引与微弱视差；
- 图像章节进入视口时的字符显影/重组；
- 按钮和功能卡片的字符边框流动；
- 手动“场景强度”开关，切换安静与高能状态。

用户启用系统“减少动态效果”、页面不可见或设备极低性能时，非关键信息动效可以暂停或减密；正常桌面体验一律全效果开启。

## 实现边界

- 单页原生 HTML、CSS 和 JavaScript；无需构建步骤。
- 图片作为真实产品视觉，ASCII 动效由浏览器实时生成。
- 导航、CTA、场景强度开关、鼠标互动和滚动显影均可操作。
- 不添加自动化测试；以人工验收代替。

## 人工验收

1. 桌面端首屏能显示主图与连续字符动效，鼠标靠近会出现反馈。
2. 滚动到两个功能图时能看见不同的字符显影或网格重组。
3. 场景强度按钮能在安静与高能状态之间切换。
4. 顶栏导航能定位至对应章节，CTA 有明确反馈。
5. 在窄屏下文本不溢出、按钮可点击，核心字符动效仍可见。
6. 在桌面与手机浏览器手动检查图片加载、滚动和交互是否流畅。
